# Foundation & Core Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold the `kv-silver-mobile` Flutter app and build its core layer — API client with typed error handling, secure JWT storage, auth-session state, the pricing engine ported from the web app, app theme, and a router skeleton that redirects based on auth state — so later feature plans (Auth, Shop/Product, Cart/Checkout, Orders) have a working app shell and stable interfaces to build on.

**Architecture:** Feature-first Flutter app. `lib/core/` holds cross-cutting concerns with no UI feature logic; `lib/features/*` (added by later plans) will consume `core/` exclusively through the providers and classes this plan defines. State is Riverpod (`StateNotifierProvider`, no codegen). Navigation is `go_router`, driven by a Riverpod-backed auth session so redirects react to login/logout automatically.

**Tech Stack:** Flutter (stable channel) + Dart, `flutter_riverpod`, `go_router`, `dio`, `flutter_secure_storage`. No `razorpay_flutter` yet — added by the Cart/Checkout plan when it's first used (YAGNI).

## Global Constraints

- Dart SDK constraint: `^3.4.0` (enables `sealed class`, used for the exception hierarchy).
- Package/project name: `kv_silver_mobile` (Dart identifiers can't contain hyphens; the repo directory `kv-silver-mobile` keeps the hyphen).
- Android application ID / iOS bundle ID org: `com.kvsilverzone` (assumption — no existing mobile bundle ID was specified; flag for the user to confirm before a store submission, but it does not block development).
- No code generation: no `build_runner`, `json_serializable`, or `riverpod_generator`. State uses the classic `StateNotifierProvider` API; JSON (de)serialization in later plans is hand-written `fromJson`/`toJson`.
- API base URL: `String.fromEnvironment('API_BASE_URL', defaultValue: 'http://10.0.2.2:5000/api/v1')` — `10.0.2.2` is the Android emulator's alias for the host machine's `localhost`, matching a local `kv-api` dev server on port 5000. Real builds pass `--dart-define=API_BASE_URL=<url>`.
- Pricing math must byte-for-byte match `kv-silver-zone/src/lib/pricing.ts` (verified via the same test fixtures as `kv-silver-zone/src/lib/pricing.test.ts`) — the app's displayed prices must agree with the website's.
- Money values are `double` rupees (not paise) in this layer, matching the web's `pricing.ts` — matches the "display only" contract; the server remains authoritative at checkout (later plan).

```dart
// lib/core/api/api_exception.dart
import 'package:dio/dio.dart';

sealed class ApiException implements Exception {
  const ApiException(this.message);
  final String message;

  @override
  String toString() => message;
}

class NetworkException extends ApiException {
  const NetworkException(super.message);
}

class AuthException extends ApiException {
  const AuthException(super.message);
}

class ValidationException extends ApiException {
  const ValidationException(super.message, this.fieldErrors);
  final Map<String, String> fieldErrors;
}

class ServerException extends ApiException {
  const ServerException(this.statusCode, super.message);
  final int statusCode;
}

const _networkErrorTypes = {
  DioExceptionType.connectionError,
  DioExceptionType.connectionTimeout,
  DioExceptionType.receiveTimeout,
  DioExceptionType.sendTimeout,
};

ApiException mapDioException(DioException e) {
  if (_networkErrorTypes.contains(e.type) || e.response == null) {
    return const NetworkException('Unable to reach the server. Check your connection.');
  }

  final response = e.response!;
  final statusCode = response.statusCode ?? 0;
  final message = _extractMessage(response.data) ?? 'Something went wrong.';

  if (statusCode == 401) {
    return AuthException(message);
  }
  if (statusCode == 400 || statusCode == 422) {
    return ValidationException(message, _extractFieldErrors(response.data));
  }
  return ServerException(statusCode, message);
}

String? _extractMessage(dynamic data) {
  if (data is Map<String, dynamic>) {
    final message = data['message'];
    if (message is String) return message;
    final error = data['error'];
    if (error is Map<String, dynamic> && error['message'] is String) {
      return error['message'] as String;
    }
  }
  return null;
}

Map<String, String> _extractFieldErrors(dynamic data) {
  if (data is Map<String, dynamic> && data['errors'] is Map) {
    final raw = data['errors'] as Map;
    return raw.map((key, value) => MapEntry(key.toString(), value.toString()));
  }
  return const {};
}
```

// lib/core/api/api_client.dart
import 'package:dio/dio.dart';
import '../config/env.dart';
import '../storage/secure_token_storage.dart';
import 'api_exception.dart';

Dio buildDio({
  required SecureTokenStorage tokenStorage,
  required Future<void> Function() onUnauthorized,
}) {
  final dio = Dio(
    BaseOptions(
      baseUrl: Env.apiBaseUrl,
      connectTimeout: const Duration(seconds: 15),
      receiveTimeout: const Duration(seconds: 15),
    ),
  );

  dio.interceptors.add(
    InterceptorsWrapper(
      onRequest: (options, handler) async {
        final token = await tokenStorage.readToken();
        if (token != null && token.isNotEmpty) {
          options.headers['Authorization'] = 'Bearer $token';
        }
        handler.next(options);
      },
      onError: (error, handler) async {
        if (error.response?.statusCode == 401) {
          await onUnauthorized();
        }
        handler.next(error);
      },
    ),
  );

  return dio;
}

class ApiClient {
  ApiClient(this._dio);

  final Dio _dio;

  Future<dynamic> get(String path, {Map<String, dynamic>? query}) async {
    try {
      final response = await _dio.get(path, queryParameters: query);
      return response.data;
    } on DioException catch (e) {
      throw mapDioException(e);
    }
  }

  Future<dynamic> post(String path, {Object? data}) async {
    try {
      final response = await _dio.post(path, data: data);
      return response.data;
    } on DioException catch (e) {
      throw mapDioException(e);
    }
  }

  Future<dynamic> put(String path, {Object? data}) async {
    try {
      final response = await _dio.put(path, data: data);
      return response.data;
    } on DioException catch (e) {
      throw mapDioException(e);
    }
  }

  Future<dynamic> delete(String path) async {
    try {
      final response = await _dio.delete(path);
      return response.data;
    } on DioException catch (e) {
      throw mapDioException(e);
    }
  }
}

// lib/core/auth/auth_session.dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../storage/secure_storage_client.dart';
import '../storage/secure_token_storage.dart';

class AuthSessionState {
  const AuthSessionState({required this.isAuthenticated, required this.isRestoring});

  final bool isAuthenticated;
  final bool isRestoring;

  static const initial = AuthSessionState(isAuthenticated: false, isRestoring: true);

  AuthSessionState copyWith({bool? isAuthenticated, bool? isRestoring}) => AuthSessionState(
        isAuthenticated: isAuthenticated ?? this.isAuthenticated,
        isRestoring: isRestoring ?? this.isRestoring,
      );
}

class AuthSessionController extends StateNotifier<AuthSessionState> {
  AuthSessionController(this._tokenStorage) : super(AuthSessionState.initial);

  final SecureTokenStorage _tokenStorage;

  Future<void> restoreSession() async {
    final token = await _tokenStorage.readToken();
    state = state.copyWith(
      isAuthenticated: token != null && token.isNotEmpty,
      isRestoring: false,
    );
  }

  Future<void> setToken(String token) async {
    await _tokenStorage.saveToken(token);
    state = state.copyWith(isAuthenticated: true, isRestoring: false);
  }

  Future<void> clearSession() async {
    await _tokenStorage.clearToken();
    state = state.copyWith(isAuthenticated: false, isRestoring: false);
  }
}

final secureTokenStorageProvider = Provider<SecureTokenStorage>((ref) {
  return SecureTokenStorage(FlutterSecureStorageClient());
});

final authSessionProvider = StateNotifierProvider<AuthSessionController, AuthSessionState>((ref) {
  return AuthSessionController(ref.watch(secureTokenStorageProvider));

// lib/core/pricing/pricing.dart

/// Shared product price engine — ports kv-silver-zone/src/lib/pricing.ts to Dart
/// so the app's displayed prices match the website exactly. Display only: the
/// server re-prices authoritatively at checkout.
enum ChargeType { percentage, amount }

class ProductCharge {
  const ProductCharge({required this.type, required this.value});
  final ChargeType type;
  final double value;
}

class MetalRate {
  const MetalRate({
    required this.id,
    required this.date,
    required this.ratePerGram,
    required this.ratePerKg,
    required this.purity,
    this.updatedBy,
  });

  final String id;
  final String date;
  final double ratePerGram;
  final double ratePerKg;
  final String purity;
  final String? updatedBy;
}

double? parseGrams(String? weight) {
  if (weight == null) return null;
  final match = RegExp(r'[\d.]+').firstMatch(weight);
  if (match == null) return null;
  final grams = double.tryParse(match.group(0)!);
  return (grams != null && grams > 0) ? grams : null;
}

double? parsePurityFraction(String? purity) {
  if (purity == null) return null;
  final match = RegExp(r'[\d.]+').firstMatch(purity);
  if (match == null) return null;
  final n = double.tryParse(match.group(0)!);
  if (n == null || n <= 0) return null;
  return n > 100 ? n / 1000 : n / 100;
}

MetalRate? matchSilverRate(List<MetalRate> rates, String? purity) {
  if (rates.isEmpty) return null;
  final frac = parsePurityFraction(purity);
  for (final r in rates) {
    final rf = parsePurityFraction(r.purity);
    if (frac != null && rf != null && (rf - frac).abs() < 0.01) {
      return r;
    }
  }
  return rates.first;
}

double resolveChargeAmount(ProductCharge? charge, double base) {
  if (charge == null || charge.value < 0) return 0;
  return charge.type == ChargeType.amount ? charge.value : (base * charge.value) / 100;
}

class ProductPricingInput {
  const ProductPricingInput({
    required this.price,
    required this.isFixedPrice,
    this.weight,
    this.weightInGrams,
    this.purity,
    this.makingCharge,
    this.wastage,
  });

  final double price;
  final bool isFixedPrice;
  final String? weight;
  final double? weightInGrams;
  final String? purity;
  final ProductCharge? makingCharge;
  final ProductCharge? wastage;
}

class ProductPriceBreakdown {
  const ProductPriceBreakdown({
    required this.isFixedPrice,
    required this.computed,
    required this.ratePerGram,
    required this.grams,
    required this.metalValue,
    required this.makingCharge,
    required this.wastage,
    required this.preGstPrice,
  });

  final bool isFixedPrice;
  final bool computed;
  final double? ratePerGram;
  final double? grams;
  final double? metalValue;
  final double? makingCharge;
  final double? wastage;
  final double preGstPrice;
}

ProductPriceBreakdown computeProductPricing(
  ProductPricingInput product,
  List<MetalRate> rates, {
  double? gramsOverride,
}) {
  final fallback = ProductPriceBreakdown(
    isFixedPrice: product.isFixedPrice,
    computed: false,
    ratePerGram: null,
    grams: null,
    metalValue: null,
    makingCharge: null,
    wastage: null,
    preGstPrice: product.price,
  );

  if (product.isFixedPrice) return fallback;

  final hasConfiguredCharge = product.makingCharge != null || product.wastage != null;
  final grams = gramsOverride ?? product.weightInGrams ?? parseGrams(product.weight);
  final ratePerGram = matchSilverRate(rates, product.purity)?.ratePerGram;

  if (grams == null || grams <= 0 || ratePerGram == null || !hasConfiguredCharge) {
    return fallback;
  }

  final metalValue = grams * ratePerGram;
  final makingCharge = resolveChargeAmount(product.makingCharge, metalValue);
  final wastage = resolveChargeAmount(product.wastage, metalValue);

  return ProductPriceBreakdown(
    isFixedPrice: false,
    computed: true,
    ratePerGram: ratePerGram,
    grams: grams,
    metalValue: metalValue,
    makingCharge: makingCharge,
    wastage: wastage,
    preGstPrice: metalValue + makingCharge + wastage,
  );
}

class OrderSummaryInput {
  const OrderSummaryInput({
    required this.subtotal,
    this.taxableSubtotal,
    this.discount = 0,
    required this.gstPercent,
    this.deliveryCharge = 0,
  });

  final double subtotal;
  final double? taxableSubtotal;
  final double discount;
  final double gstPercent;
  final double deliveryCharge;
}

class OrderSummary {
  const OrderSummary({
    required this.subtotal,
    required this.discount,
    required this.discountedSubtotal,
    required this.gst,
    required this.deliveryCharge,
    required this.total,
  });

  final double subtotal;
  final double discount;
  final double discountedSubtotal;
  final double gst;
  final double deliveryCharge;
  final double total;
}

OrderSummary computeOrderSummary(OrderSummaryInput input) {
  final taxable = input.taxableSubtotal ?? input.subtotal;
  final safeDiscount = input.discount.clamp(0, input.subtotal).toDouble();
  final discountedSubtotal = (input.subtotal - safeDiscount).clamp(0, double.infinity).toDouble();
  final taxableAfterDiscount = (taxable - safeDiscount).clamp(0, double.infinity).toDouble();
  final gst = (taxableAfterDiscount * input.gstPercent) / 100;

  return OrderSummary(
    subtotal: input.subtotal,
    discount: safeDiscount,
    discountedSubtotal: discountedSubtotal,
    gst: gst,
    deliveryCharge: input.deliveryCharge,
    total: discountedSubtotal + gst + input.deliveryCharge,
  );
}
